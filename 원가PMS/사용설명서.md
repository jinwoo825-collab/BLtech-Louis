# 하이드로겔 제조원가 PMS — 사용 설명서

비엘테크(주) 원주 하이드로겔 사업부 · 공급가 산정 도구

## 1. 실행 방법 (매번 같은 방법으로 여세요)

**바탕화면의 `하이드로겔 원가계산기` 아이콘을 더블클릭**하면 기본 브라우저(크롬/엣지)에서 열립니다.
- 별도 설치·인터넷 연결 불필요.
- 아이콘이 없으면 `문서\BLtech-Louis3\원가PMS\index.html` 파일을 더블클릭해도 됩니다.

> ⚠️ **중요 — 항상 같은 방법(바탕화면 아이콘)으로 여세요.**
> 데이터는 "그 파일을 연 그 브라우저"에 저장됩니다. 다른 방법(예: 임시 미리보기 주소)으로 열면
> 저장 공간이 달라 이전에 입력한 값이 안 보일 수 있습니다.

## 2. 자동 저장

- 값을 입력할 때마다 **자동으로 내 컴퓨터(브라우저 저장소)에 저장**됩니다.
- 화면 오른쪽 위에 `✔ 자동 저장됨 (시각)` 표시가 뜹니다.
- 브라우저를 닫았다 다시 열어도 마지막 상태가 유지됩니다.

## 3. 백업 (중요한 데이터는 꼭 파일로도 저장)

브라우저 데이터는 "인터넷 사용기록/캐시 삭제" 시 함께 지워질 수 있습니다.
중요한 원가표는 주기적으로 파일 백업을 권장합니다.

- **백업 내보내기** 버튼 → `hydrogel-cost-날짜.json` 파일로 저장됩니다. (내 문서 등 안전한 곳에 보관)
- **가져오기** 버튼 → 백업한 .json 파일을 불러와 복원합니다.
- 다른 PC로 옮길 때도 이 방법으로 이동합니다.

## 4. 화면 구성

### [원가 계산] 탭
1. **원료 배합** — 원료명·Kg당 단가·배합비% → 배합원가(원/kg)
2. **원단(쉬트)** — 겔 비중×두께로 겔 중량, + 원단단가(원/㎡) = 겔쉬트 1장 원료비
3. **제품 사이즈** — 시트 면적 ÷ (제품+간격) = 시트당 제품수, 제품 1개당 원료비
4. **포장** — 파우치·박스 단가와 입수량
5. **로스·마진** — 파우치 단위 로스율, 목표 마진율
6. **인건비·기타 제조비용** — 인력수준×인원수(1일 인건비), 월 기타비용 ÷ 가동일수, 1일 생산 CAPA로 배분
- **결과**: 최종 제조원가/개, 권장 공급가/개, 원가 구성, 시나리오 비교

### [단가 마스터] 탭 (가격 저장소)
①원료 ②원단(원/㎡) ③파우치 ④박스 ⑤인건비(인력수준·일당) ⑥기타제조비용(월비용)
- 여기서 등록한 단가는 자동 저장되고, 원가 계산 화면에서 선택해 불러 씁니다.
- 원료 단가가 바뀌면 여기서 한 번만 고치면 됩니다.

## 5. 시나리오 비교

원료·조건을 바꾼 뒤 상단에 이름을 넣고 **시나리오 저장** → 오른쪽 비교표에
배합원가·제조원가·공급가가 쌓여 안(案)별로 비교됩니다. (최저안 자동 표시)
