# PM 워크스페이스 — 개인 프로젝트 매니지먼트

일할 때 옆에 켜두고 참고하는 가벼운 개인용 칸반/할일 관리 도구입니다.
설치·서버·인터넷 연결이 필요 없습니다. **`index.html`을 브라우저로 열기만** 하면 됩니다.

## 실행 방법
`test1/index.html` 파일을 더블클릭 → 크롬/엣지 등에서 열림.

## 주요 기능
- **프로젝트별 분류**: 좌측에서 프로젝트를 만들고 색상으로 구분 (전체 보기 지원)
- **칸반 보드**: 할 일 / 진행 중 / 완료 3단계, 카드를 **드래그**해서 상태 이동
- **할 일 카드**: 제목, 우선순위(높음·보통·낮음), 마감일, 메모
- **대시보드 통계**: 전체·할일·진행중·완료율·기한 초과 한눈에 보기
- **마감 알림 색상**: 기한 초과(빨강) / 임박 2일 이내(주황) 자동 표시
- **백업**: 상단 `내보내기`로 JSON 저장, `가져오기`로 복원

## 데이터 저장 위치
브라우저 `localStorage`에 자동 저장됩니다.
- 같은 브라우저에서 다시 열면 데이터가 유지됩니다.
- 다른 PC/브라우저로 옮기거나 백업하려면 `내보내기` 기능을 사용하세요.
- 브라우저 캐시/사이트 데이터를 지우면 초기화되니, 중요한 데이터는 주기적으로 내보내 두는 걸 권장합니다.

## 단축키
- `Esc` : 열려 있는 창 닫기
